# VAD AR 主工程

新版体验流程：

1. 打开首页并启动 AR，扫描识别物。
2. 三个精灵出现在识别物前方并可进行触屏交互。
3. 识别成功后，页面底部出现“去合影”按钮。
4. 点击后进入小游戏，通过收集星星解锁不同合照模板。
5. 选择模板后调用前置摄像头，将真人脸部裁切并拼贴到预制身体。

## 页面

- `index.html`：构建后的 MindAR 入口页。
- `game.html`：小游戏、星级解锁和合照页。
- `ar-source/`：AR 入口的 Vite 源码。

## 本地构建

在 `ar-source` 内安装依赖并执行：

```bash
npm run build
```

再将 `ar-source/dist/` 内的输出复制到仓库根目录。部署目标保持为仓库根目录。
